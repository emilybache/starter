Sample Project
==============

For exercise instructions see [top level README](../README.md)

### Create and activate virtual environment

On macOS/Linux:

    python3 -m venv .venv
    source .venv/bin/activate

On Windows:

    python -m venv .venv
    .venv\Scripts\activate

### Install dependencies

    pip install --upgrade pip
    pip install -e .

## Run tests

    pytest
